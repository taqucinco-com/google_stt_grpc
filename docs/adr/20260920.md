# ADR 2026-09-20: gRPCサーバーの土台を作る(Step 1/3)

## Status

Accepted

## Context

このプロジェクトの最終目標は、iOSアプリからGoogle Cloud Speech-to-Text (STT) の
gRPC streaming APIを利用することである。いきなりGoogle STTに繋ぎ込むと問題の切り分けが
難しいため、以下の3ステップで段階的に進める。

1. **簡単なgRPCサーバーを立てる**(このADRの対象)
2. iOS Swift側でgRPC Clientの実装を確立する
3. (1)(2)の土台をGoogle STT gRPCに適用する

Step 1のリファレンスとして、以前作成した
[chat_and_voip](https://github.com/taqucinco-com/chat_and_voip) リポジトリの
`grpc/src/example.com/helloworld` を利用する。あちらはunary / server streaming /
client streaming / bidirectional streamingの4パターンを持つ`Greeter`サービスを
実装しており、STTのstreaming APIを試す前段の練習台として適している。

## Decision

- リポジトリルート直下に `grpc/` ディレクトリを作成し、Goのgrpcサーバーを実装する。
  - `grpc/helloworld/helloworld.proto` — chat_and_voipと同じ`Greeter`サービス定義
    (`SayHello`, `SayHelloAgain`, `SayHelloToMany`, `SayChat`)。`go_package`のみ
    このリポジトリのモジュールパスに合わせて変更。
  - `protoc --go_out --go-grpc_out` で生成した`*.pb.go`はリポジトリにコミットする
    (protocのインストールをDocker buildの必須要件にしないため)。
  - `grpc/main.go` — 単一の`main`パッケージでサーバーを起動。`Greeter`サービスを登録し、
    `reflection.Register`でリフレクションを有効化する(grpcurlでの動作確認のため)。
- `docker-compose.yml` をリポジトリルートに置き、`grpc`サービスとして
  `50051`番ポートを公開する。
- 動作確認は `grpcurl -plaintext localhost:50051 list` / `list greeter.Greeter` /
  実際のRPC呼び出し(`SayHello`等)で行う。

### 確認したコマンド

```bash
$ docker compose up -d --build
$ grpcurl -plaintext localhost:50051 list
greeter.Greeter
grpc.reflection.v1.ServerReflection
grpc.reflection.v1alpha.ServerReflection

$ grpcurl -plaintext localhost:50051 list greeter.Greeter
greeter.Greeter.SayChat
greeter.Greeter.SayHello
greeter.Greeter.SayHelloAgain
greeter.Greeter.SayHelloToMany

$ grpcurl -plaintext -d '{"name": "taro"}' localhost:50051 greeter.Greeter.SayHello
{
  "message": "Hello taro"
}
```

## Consequences

- Step 2(iOS Swift gRPC Client)は、このサーバーの`Greeter`サービスを疎通確認の
  対象にできる。TLSなし(`-plaintext`)のローカル開発用構成なので、Swift側も
  `insecure`な接続で最初は試すことになる。
- Step 3でGoogle STTのstreaming APIに置き換える際は、`SayChat`
  (bidirectional streaming)の実装パターンをそのまま応用できる見込み。
- protoファイルはリポジトリにコミットするが、生成物(`*.pb.go`)もコミットするため、
  proto変更時は手動で再生成コマンドを実行する必要がある(下記コマンド、AGENTS.md参照)。
